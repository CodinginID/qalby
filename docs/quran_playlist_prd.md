# Quran Memorization Playlist App (Final PRD + Sprint Plan)

## 1. Product Overview
Mobile app (Flutter) for:
- Quran memorization playlist (non-linear)
- Spiritual support (recommendation categories)
- Islamic lifestyle (prayer, sunnah, qibla)

---

## 2. Core Features (MVP)
- User Auth
- Quran Browser
- Playlist Hafalan (non-linear)
- Practice Mode
- Recommendation Categories (static)

---

## 3. Secondary Features
- Prayer Time & Reminder
- Sunnah Tracker
- Qibla Direction

---

## 4. Future Features
- AI Recitation
- Smart Recommendation
- Adaptive Reminder

---

## 5. Tech Stack
- Mobile: Flutter
- Backend: Go / Flask
- DB: MongoDB

---

## 6. Sprint Plan (4 Weeks)

### Sprint 1
- Setup Flutter project
- Auth UI
- Quran list UI

### Sprint 2
- Playlist CRUD
- Add ayat (range)
- Reorder list

### Sprint 3
- Practice mode
- Basic tracking
- Recommendation UI

### Sprint 4
- Prayer time integration
- Notification
- Qibla compass
